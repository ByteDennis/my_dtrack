pair_recon 0.1.0 — 2026-10-18

Added
- Interactive Bash/CMD launcher with saved UTF-8 YAML defaults and one pair per run.
- Unity Catalog metadata, run-status, run-error, and Volume artifact integration.
- Resume, restart, and cancel handling for existing run IDs; resume keeps matches and retries failed or different checks.
- Pair-level row_count, hash_sum, and n_unique selection.
- Pair-level partition_mode=date|all and snapshot alignment to the latest matching Right history partition.
- Persistent named Left logging and local Win32 Outlook result delivery with the Left log attached.
- One-time Databricks Right package/job setup and optional Delta table schema.
- Focused unit, packaging, Outlook, snapshot, UTF-8, Volume, and opt-in live Oracle query/export/timing tests.

Changed
- Renamed every shipped package, command, environment prefix, artifact, job, and configuration surface to pair_recon.
- Reduced src and tests directory fan-out to at most five direct children per folder.
- Simplified every test function name to at most two underscore-separated words and retained parametrization.
- Standardized local timestamps on a confirmed IANA timezone and stored wall-clock values as TIMESTAMP_NTZ.
- Replaced root/basic logging setup with one stable pair_recon logger tree and one run-scoped Left log.

Removed functionality
- Dashboard, progress snapshot collector, and Databricks alert delivery.
- S3/AWS credential relay, WinSCP helpers, Athena, Hadoop, CSV, DuckDB, and SAS source paths.
- Confluence publishing, HTML/Excel report generation, blog tooling, and report templates.
- Alternate local dual-connection pipeline, key-check command, multi-pair CLI, manual rollback command, and legacy examples/notebooks.
- Deprecated query-projection configuration and unused helpers, adapters, tests, dependencies, and generated legacy archives.

Preserved functionality
- Oracle Left extraction, Databricks/Spark Right validation, deterministic sampling, date/all partitions, vintage windows, normalization, query-window SQL, selective statistics, resumable protocol artifacts, and SQL audit evidence.

Verification
- ruff check and ruff format --check pass.
- 487 unit tests pass and 12 optional tests skip.
- Wheel and source distribution build successfully.
- Live tests remain opt-in and were not executed.
