DTrack change log — 2026-10-17

This file intentionally replaces the previous history and records only the current cleanup.

Changed

- Enforced a maximum of five direct, non-generated child items in every directory under `src/`
  and `tests/`.
- Reorganized Left modules into `backends/cloud`, `cli/commands`, and the
  `common/{checks,model,runtime,sql}` domains.
- Reorganized local-only adapters under `dtrack_local/support`.
- Reorganized the standalone Databricks package under `dtrack_right/engine` while keeping
  `notebook.py`, `progress.py`, and `requirements.txt` at the upload root.
- Reorganized unit tests into `common/{data,protocol,runtime}`, `flows`, and `packages`; moved
  the tracked live-source contract under `tests/live/sources`.
- Updated source, test, example, notebook, CLI, Workspace-upload, and guidance references to the
  canonical module paths.
- Kept UTF-8 file handling and Windows/Linux path behavior unchanged.

Merged and removed

- Merged `src/dtrack_left/cli/debugging.py` into
  `src/dtrack_left/cli/commands/tools.py` and removed the standalone debugger module.
- Merged `src/dtrack_left/csv_sampling.py` into
  `src/dtrack_left/common/sql/sampling.py` and removed the standalone CSV sampler.
- Removed obsolete package marker files where implicit namespace directories are sufficient.
- Removed empty legacy source/test directories and generated caches left behind by the moves.

Tests

- Added a recursive layout contract for both `src/` and `tests/`.
- Added an isolated standalone-Right import test and a real-package Workspace upload dry-run.
- Preserved the one-to-two-word test-name policy and updated moved test imports and fixtures.
- Live services were not executed; `tests/live` remains operator-run.

File manifest

`M` = modified, `R` = moved (and updated where needed), `D` = deleted.
