pair_recon Wide-table statistics and runtime controls — 2026-10-28

Summary
- Splits Right-side statistics into batches of `RIGHT_STATS_COLUMNS` columns (default 50), avoiding very large Spark aggregate plans on wide tables.
- Publishes per-window `fetching` progress to `_protocol/right.json` after every statistics batch.
- Retries torn JSON state reads on both the local Files API store and the Databricks Volume FUSE store.
- Adds case-insensitive `excluded_columns` run defaults and an `Excluded columns` prompt, rejecting unknown mapped-column names.
- Reduces the default difference sample limit from 1000 to 100 rows.
- Raises the default Right first-result and state-stall watchdog limits to 14400 and 7200 seconds.
