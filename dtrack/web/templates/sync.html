SYNC INSPECTOR

Why this exists: three fields can be edited from both the web UI and the dtrack.json file directly. When the two get out of sync you can see and reconcile them here.

  • col_map — left↔right column name mapping. UI: Col Mapping page; JSON: pair.col_map.
  • col_filter — include/exclude glob patterns. UI: Col Gen page; JSON: pair.col_filter.
  • where_map — date-range WHERE per side. DB-only, computed from _row_comparison at gen-time; pushable to JSON for inspection only.

Other fields (vintage, fromDate/toDate, structural shape, extracted row/col stats, comparison results) live in only one place and aren't compared here.
