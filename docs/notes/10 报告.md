## report 桶：history 先写，pointer 最后写

```python
def publish_report(report_store, run_id, files, summary):
    for name, path in sorted(files.items()):
        report_store.put_bytes(f"history/{run_id}/{name}", path.read_bytes(), content_type=...)   # 不可变归档
    report_store.put_json("latest/pointer.json", {"run_id", "finished_at", "status", "findings", "base"})   # 唯一入口
```

S3 没有多文件事务；逐个覆盖 `latest/` 会让 dashboard 读到半新半旧，所以归档写 `history/{run_id}/`，
`latest/` 只放一个指针。`tests/cloud/test_report.py` 断言最后一次 put 就是 `latest/pointer.json`，
并验证 publish → fetch 往返后字节相同。report 桶同样可以是 Volume 路径（`open_store`）。
