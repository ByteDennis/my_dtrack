# 01 配置与连接档案

上一步：[[12 Databricks 作业]] · 下一步：[[02 Stage 1 左侧计数]] · 索引：[[00 索引]]

配置文件只在**本地**读取。每个本地命令的第一件事都是 `load_config`：读 `.env`、读 JSON、展开连接
档案、校验硬约束。云端从不看这个文件，它需要的 pair 信息由 Stage 1 剥掉凭据后随
`stage1/<pair>.left.json` 一起送到 S3（[[02 Stage 1 左侧计数]]）。

## 配置形状

```jsonc
{
  "connections": {                       // 可复用的连接档案，凭据只写环境变量名
    "ora_pcds": {"source": "oracle", "dsn": "pcds-scan:1521/PCDS",
                 "user_env": "PCDS_USER", "password_env": "PCDS_PASSWORD"},
    "dbx_main": {"source": "databricks"}  // 右侧档案现在只是占位：本地不连 Databricks
  },
  "pairs": {
    "orders": {
      "left":  {"conn_macro": "ora_pcds", "schema": "FINANCE", "table": "ORDERS",
                "date_col": "BUSINESS_DATE", "date_type": "date"},
      "right": {"conn_macro": "dbx_main", "catalog": "main", "schema": "sales",
                "table": "orders", "date_col": "business_date", "date_type": "date"},
      "fromDate": "2026-01-01", "toDate": "2026-02-28",
      "vintage": "month", "key": "ORDER_ID", "key_families": {"ORDER_ID": "numeric"},
      "sample": 0.25, "strict": false,
      "col_map": {"ORDER_ID": "order_id", "AMOUNT": "amount"}
    }
  }
}
```

多个 Oracle server（账户 / 密码 / service name 各异）靠 `connections` 里的多份档案区分；右侧只需要
`catalog/schema/table/date_col/date_type`，这些会原样传给云端，云端用自己的 `spark.sql` 去读。

## 展开 `conn_macro`

```python
# src/dtrack_distributed/config.py
def resolve_connections(config):
    profiles = config.get("connections") or {}
    for name, pair in config["pairs"].items():
        for side in ("left", "right"):
            macro = (pair.get(side) or {}).get("conn_macro")
            if not macro: continue
            if macro not in profiles:
                if spec.get("source") == "csv": continue     # csv 的 conn_macro 是文件路径，沿用旧语义
                raise ValueError(f"{name}: unknown conn_macro {macro!r} for {side}")
            pair[side] = {**profiles[macro], **spec}          # pair 内字段覆盖档案
    return config
```

## 硬约束

```python
LEFT_SOURCES = {"oracle", "athena", "aws", "hadoop", "csv"}
if left_source not in LEFT_SOURCES: raise ValueError(...)   # sas 明确不在
if right_source != "databricks":     raise ValueError(f"{name}: Right side must be databricks")
if not pair.get("col_map"):          raise ValueError(f"{name}: col_map must be non-empty")
```

右侧只能是 Databricks 是整套设计的前提：云端只需要一个适配器（[[07 采样与统计]] 里的 `SparkTarget`）。

## 凭据从哪来，到哪为止

```python
# adapters/sources/oracle.py
self.user = config.get("user") or os.getenv(config.get("user_env", "ORACLE_USER"))
self.dsn  = config.get("dsn")  or os.getenv(config.get("dsn_env", "ORACLE_DSN"))
```

`*_env` 只写变量名，`.env` 或 shell 提供值。往 S3 写 pair 配置时统一剥掉：

```python
# workflows/stage1.py
SECRET_FIELDS = {"user", "password", "access_token", "dsn", "server_hostname", "http_path"}
def public_pair_config(pair):
    for side in ("left", "right"):
        result[side] = {k: v for k, v in pair[side].items() if k not in SECRET_FIELDS and not k.endswith("_env")}
```

`tests/test_stage1.py` 断言 `dsn`、`password`、`user_env` 都不会出现在 `stage1/<pair>.left.json` 里。
