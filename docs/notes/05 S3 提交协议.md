# 05 S3 提交协议

上一步：[[04 Gate 与 manifest]] · 下一步：[[06 Producer]] · 索引：[[00 索引]]

两侧从不直接通话，只认 S3 上的文件。协议的全部就一句：**先写数据对象，再写指针对象。**

## 布局（一个 run 一个前缀，标注谁写）

```
s3://work/dtrack/v1/runs/{run_id}/
  _STATUS.json                 谁在干活谁覆写（role: left / right）
  _HEARTBEAT                   本地 Producer 活着吗 {"epoch_s": ...}
  stage1/{pair}.left.json      LEFT   左侧计数 + 无凭据 pair 配置   ← 云端等的第一个信号
  stage1/_LEFT_CLOSED          LEFT   左侧 pair 清单
  stage1/{pair}.json           RIGHT  全部 partition 的 verdict
  stage1/_CLOSED               RIGHT  全部 pair 对账完              ← 本地 produce 等的信号
  reports/{pair}_compare_row.csv  RIGHT
  manifest/{pair}.json         RIGHT  只含过关 partition 的执行计划
  manifest/{pair}.keys.json    LEFT   fixed-N 模式选出的 key
  manifest/_CLOSED             LEFT   {pairs, expected_units}
  units/{unit_id}.json         LEFT   ← 数据（列统计）
  _INDEX/{seq:08d}-{unit_id}.json  LEFT  ← 指针，云端只扫这个
  results/{unit_id}.json       RIGHT
  dead/{unit_id}.json          RIGHT  重试耗尽
s3://report/
  history/{run_id}/…           RIGHT  summary.json · csv · index.html · report.xlsx
  latest/pointer.json          RIGHT  最后写的唯一入口
```

## 原子提交

```python
# adapters/storage/s3.py（本地）与 dtrack_cloud/s3.py（云端）相同
def commit_unit(self, sequence, unit_id, payload, pointer):
    payload_key = f"units/{unit_id}.json"
    self.put_json(payload_key, payload)                                   # 1. 数据
    document = {**pointer, "unit_id": unit_id, "payload_key": payload_key, "sequence": int(sequence)}
    self.put_json(f"_INDEX/{sequence:08d}-{unit_id}.json", document)      # 2. 指针
```

S3 单对象 PUT 原子、LIST 强一致，云端只从 `_INDEX/` 发现工作，就不可能读到半截文件。

## 两种存储后端（云端）

```python
# databricks/dtrack_cloud/store.py
def open_store(location, *, kms_key_id=None):
    if location.startswith("s3://"): return S3Store(location, kms_key_id=kms_key_id)   # boto3 + instance profile
    return VolumeStore(location)                                                        # /Volumes/... 纯文件 IO
```

`VolumeStore` 与 `S3Store` 同一套方法（`put_json` / `list_keys(start_after)` / `commit_unit` /
`heartbeat_age` / ...），写文件先写 `.part` 再 `replace`，保证读方看不到半截。把 work 桶挂成
Unity Catalog Volume 后，集群上不需要任何 AWS key；本地用 boto3 写同一个桶。
`tests/cloud/test_cloud.py::test_volume_store_*` 验证先数据后指针和增量列举。

## 心跳、收摊、背压

```python
def heartbeat(self):        put_json("_HEARTBEAT", {"epoch_s": time.time()})
def heartbeat_age(self):    None if 无心跳文件 else now - epoch_s
def close_manifests(pairs, expected_units):  put_json("manifest/_CLOSED", {...})
def ready_unclaimed(self):  |_INDEX| - |results| - |dead|
```

`manifest/_CLOSED` 是本地对云端说的唯一一句话："我推完了，一共 N 个"。
