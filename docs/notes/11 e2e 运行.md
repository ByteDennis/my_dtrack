# 11 e2e 运行

上一步：[[10 报告]] · 索引：[[00 索引]]

```bash
just e2e            # = docker compose up moto + ./examples/e2e/run_e2e.sh
```

两个进程，和生产一样各跑各的：本地 CLI（`dtrack-distributed`，无 Databricks 凭据）和云端 job
（`python -m dtrack_cloud`，notebook 的本地替身，用 CSV 锚点代替 `spark.sql`）。S3 是
`dtrack-moto-1` 容器。脚本开头会记 `databricks env vars present: 0`。

## 合成数据里埋了什么

```python
# examples/e2e/make_synthetic.py
if iso == "2026-02-05": right_row[2] = f"{amount + 0.01:.2f}"    # AMOUNT diff（2026-02 窗口）
if iso == "2026-01-03": right_row[3] = status.lower()             # STATUS diff（2026-01 窗口）
if iso != "2026-01-31": left.append(left_row)                     # 左侧缺一天 -> right_only
if iso != "2026-02-10": right.append(right_row)                   # 右侧缺一天 -> left_only
right = 去掉 2026-01-15 的 3 行                                    # count_diff
# customers：右侧 TIER 全大写，pair 配 strict=true，sample=40（fixed-N）
```

## 脚本的骨架

```bash
CLOUD="env PYTHONPATH=$REPO/databricks uv run python -m dtrack_cloud"
$CLOUD --work "$S3" --report "$REPORT_S3" --right-csv-dir "$RIGHT" ... &     # 步骤 05：云端先起，后台
uv run dtrack-distributed stage1  --config ... --s3 "$S3" --run-id "$RUN_ID"  # 步骤 06
uv run dtrack-distributed produce --s3 "$S3" --wait-timeout 120               # 步骤 07：等 _CLOSED 再推
wait $CLOUD_PID                                                               # 步骤 05 结束：报告已发布
```

| 步 | 谁 | 命令 | 证明什么 |
| --- | --- | --- | --- |
| 01–02 | — | `pytest`、`pytest -m integration` | 本地 + 云端 + parity 单测，moto 协议测试 |
| 03–04 | — | `make_synthetic.py`、建两个桶 | 数据与 work / report 桶 |
| 05 | RIGHT | `python -m dtrack_cloud`（后台） | 先起、空等、见到 left.json 才动 |
| 06 | LEFT | `stage1` | 左侧计数 → `stage1/<pair>.left.json` + `_LEFT_CLOSED`（[[02 Stage 1 左侧计数]]） |
| 05 | RIGHT | 自动 | 对账、gate、manifest、`stage1/_CLOSED`，随即预取右侧（[[03 Stage 1 右侧对账]]、[[08 Consumer 调度]]） |
| 07 | LEFT | `produce` | 等 `_CLOSED`、写 `customers.keys.json`、轮转推 unit、`manifest/_CLOSED`（[[06 Producer]]） |
| 05 | RIGHT | 自动 | 比对、`results/`、报告、`history/` + `latest/pointer.json`、退出（[[10 报告]]） |
| 08–10 | 两侧 | 再跑 `produce` / 云端 / 本地 `report` | `published_units: 0`、`results: 0`、本地也能出同一份报告 |
| 11–12 | 两侧 | `--gate manual` / `ratio:0.02` 的云端 | manual 不出 manifest；ratio 挡住 orders 放行 customers；这两次云端因无 producer 按 idle timeout 退出（预期 rc=1） |
| 13–14 | — | `s3_mirror.py` | work / report 桶逐字节镜像到 `output/` |
